# Weather Fetcher (API)

A lightweight Python tool to fetch real-time weather and temperature data using Open-Meteo API.

## Features
- Dynamic location geocoding
- CLI flag and interactive input support
- Real-time temperature, wind speed, and weather condition icons using WMO standards

## Setup & Run
```bash
pip install -r requirements.txt

# Run with CLI argument
python main.py -c "Istanbul"

# Or run interactively
python main.py
